# 控制板（发送板）操作说明

控制板模拟晶圆厂设备的工艺参数采集终端：用按键和拨码改变电压、电流、温度、晶圆片号等数据，经板间串口发给看板，看板在 HDMI 屏上显示并判断是否越限。

## 1. 接线

| 控制板 | 看板 | 说明 |
|---|---|---|
| J1（TX） | P4（RX） | 控制板发数据 |
| K2（RX） | N4（TX） | 看板回 OK / ER 及工位异常状态 `!G` |
| GND | GND | 必须共地 |

串口参数 115200 8N1，3.3V 电平。上电后控制板先发 `!D0`，看板切到 LIVE 模式，再开始收数据。

## 2. 键盘（4x4）

键号按操作者视角，从左上角开始逐行编号：

```
┌────┬────┬────┬────┐
│ 0  │ 1  │ 2  │ 3  │   电压+  电压-  电流+  电流-
├────┼────┼────┼────┤
│ 4  │ 5  │ 6  │ 7  │   温度+  温度-  换设备  故障注入
├────┼────┼────┼────┤
│ 8  │ 9  │ 10 │ 11 │   下一片  缺陷+1  新批次  立即发送
├────┼────┼────┼────┤
│ 12 │ 13 │ 14 │ 15 │   选阈值  阈值+  阈值-  下发阈值
└────┴────┴────┴────┘
```

| 键 | 功能 | 步长 / 范围 | 发送 |
|---|---|---|---|
| 0 / 1 | 电压 + / - | 10mV，0~20.000V | 立即发 `!M` |
| 2 / 3 | 电流 + / - | 1mA，0~5000mA | 立即发 `!M` |
| 4 / 5 | 温度 + / - | 0.5℃，0~150.0℃ | 立即发 `!M` |
| 6 | 切换设备 | 1→2→3→1（对应工位 A/B/C） | 立即发 `!M` |
| 7 | 故障注入开/关 | 发出的温度 +30℃（本地设定值不变），LED4 亮 | 立即发 `!M` |
| 8 | 下一片晶圆 | 片号 +1；第 25 片后回到 1，批次 +1，缺陷清零 | 发 `!L` |
| 9 | 缺陷数 +1 | 最大 9999；良率 = 100.0% − 缺陷数 × 0.4% | 发 `!L` |
| 10 | 新批次 | 批次 +1，片号回 1，缺陷清零 | 发 `!L` |
| 11 | 立即发送 | 补发一次当前测量和批次数据 | 发 `!M` + `!L` |
| 12 | 选择阈值 | 不在阈值页时，第一次按只切到阈值页、显示当前阈值（上电为 U-Lo）；之后每按一次切到下一个：U-Lo → U-Hi → C-Hi → t-Hi → U-Lo | 不发送 |
| 13 / 14 | 当前阈值 + / - | 见下表 | 不发送 |
| 15 | 下发阈值 | 把 4 个阈值一起发给看板 | 发 `!T` |

阈值改完必须按 15 才会在看板上生效，只按 13/14 是本地修改。改过还没下发时，OLED 第 3 行闪 `LIMIT NOT SENT: APLY`，键盘图上的 `APLY` 也闪，按 15 后消失。

| 阈值 | 默认 | 步长 | 范围 |
|---|---|---|---|
| U-Lo 电压下限 | 3.200V | 50mV | 0V 起，且比上限低 50mV 以上 |
| U-Hi 电压上限 | 3.400V | 50mV | 最高 20.000V，且比下限高 50mV 以上 |
| C-Hi 电流上限 | 60mA | 10mA | 10~5000mA |
| t-Hi 温度上限 | 60.0℃ | 5.0℃ | 5.0~150.0℃ |

上电默认数据：电压 3.300V、电流 42mA、温度 35.0℃、设备 1、批次 1234、第 1 片、缺陷 0。

## 3. 拨码开关

| 拨码 | 引脚 | 功能 |
|---|---|---|
| SW0 | A9 | AUTO：每秒自动发 `!M`，每 4 秒发 `!L`；LED5 亮 |
| SW1 | A10 | 数据包末尾加 CRC16 校验（`*CCCC`） |
| SW2 | B10 | 叠加噪声：电压 −8~+7mV、电流 −1~+2mA、温度 −0.4~+0.3℃，模拟真实传感器 |
| SW3 | A11 | 自动走片：每 8 秒换下一片，并随机增加 0~2 个缺陷 |
| SW4 | A12 | 数码管显示收到看板 OK 的次数 |
| SW5 | B12 | 摄像头诊断页，按任意键翻页（此时按键不改数据），见第 8 节 |
| SW6 | A13 | 现场视觉模式：按键改为选图像算法、调阈值、控制云台（不改工艺数据），见第 9 节 |
| SW7 | A14 | 标定模式，见第 6 节 |

SW0 关闭时，控制板只在按键时发送。

## 4. 数码管

切换显示量时先亮 1 秒名称，再显示数值；10 秒没操作会重亮一次名称。名称亮着时按任意键会立即回到数值。

| 名称 | 读作 | 含义 | 数值示例 |
|---|---|---|---|
| `UoLt` | VOLT | 电压，单位 V | `3.300`，≥10V 时 `12.34` |
| `Curr` | CURR | 电流，单位 mA | `42` |
| `tEnP` | TEMP | 发出的温度，单位 ℃ | `35.0` |
| `tooL` | TOOL | 设备号-片号 | `2-05` = 设备 2 第 5 片 |
| `dEF` | DEF | 缺陷数 | `3` |
| `Lot` | LOT | 批次号 | `1235` |
| `U-Lo` / `U-Hi` | V-LO / V-HI | 电压下限 / 上限，单位 V | `3.200` |
| `C-Hi` | C-HI | 电流上限，单位 mA | `60` |
| `t-Hi` | T-HI | 温度上限，单位 ℃ | `60.0` |
| `Good` | GOOD | 收到 OK 次数（SW4） | `128` |
| `tE5t` | TEST | 标定模式（SW7） | `1234` |
| `CAPt` 等 | — | 摄像头诊断页（SW5），见第 8 节 | — |

最右位的小数点闪一下表示正在发送数据。

### 4.1 OLED 操作屏（与数码管联动）

0.96 寸 SSD1306 128x64 I2C 模块（地址 0x3C），SCL 接 D1，SDA 接 E1，VCC 3.3V，GND 共地。1.3 寸 SH1106 模块把 `oled_i2c_ssd1306` 的 `COL_OFFSET` 改为 2。整屏约 20 帧/秒连续刷新，热插拔后 3 秒内自动恢复。

屏幕 8 行，每行 21 字：

| 行 | 内容 |
|---|---|
| 0 | 模式（DATA / VIS / CAM / TEST）+ 链路 `LK:OK/ERR/LOST/WAIT` + 开关 `ACNW`（SW0 自动、SW1 CRC、SW2 噪声、SW3 自动走片，关为 `-`）+ `*` 正在发送 |
| 1（反色） | `7SEG>` + 数码管当前显示量的全称、数值、单位，和数码管同步，例如 `7SEG>VOLT  3.300 V` |
| 2~3 | 当前模式的关键数据：DATA 为电压/电流/温度、设备-片号/批次/缺陷；VIS 为阈值/水平/俯仰、云台状态/标定/错误 |
| 4~7 | 4x4 键盘图，位置和实物按键一一对应，写的就是按下去的作用，随拨码模式自动切换 |

键盘图的标记：

- `>`：按下会改变数码管当前显示量的键（例如数码管显示电压时，`VOL+` `VOL-` 前有 `>`）。
- 反色：当前生效的选项，例如故障注入开着时 `FALT` 反色，VIS 模式下当前算法和已启用的 `AUTO` 反色。
- 闪烁：需要处理，例如阈值改了还没下发时 `APLY` 闪，云台等人工确认时 `ACK` 闪。
- 刚按下的键反色 0.3 秒，作为按键确认。

SW5 摄像头诊断时，OLED 第 2~5 行一次列出全部诊断值（帧率、VSYNC、行数、行长、PCLK、数据位、芯片 ID、发送帧率和摄像头状态），不用逐页翻；数码管仍按键翻页，第 6 行显示当前页号。SW7 标定时，键盘图显示 `K00`~`K15`，刚按下的键反色，第 1 行显示键号和 LED 二进制。

| LED | 引脚 | 正常模式 |
|---|---|---|
| LED0 | B14 | 正在发送（闪） |
| LED1 | B15 | 上一行看板回 OK |
| LED2 | B16 | 上一行看板回 ER（数据格式或 CRC 错） |
| LED3 | C15 | 链路正常（3 秒内收到过 OK） |
| LED4 | C16 | 故障注入已开启 |
| LED5 | E13 | AUTO 已开启 |

| LED7 | F16 | 心跳，1 秒闪一次 |

## 6. 标定模式（SW7）

用于上板确认数码管位序和按键位置：

1. 拨上 SW7，数码管先亮 `tE5t`，再显示 `1234`（从左到右）。
2. 按任意键，按键不改数值、不触发发送（SW0 打开时 AUTO 仍会定时发送）。
3. LED0~LED3 以二进制显示刚按下的键号（LED0 是最低位），LED4 每按一次翻转一次。
4. 按左上角键应显示 0（LED 全灭、LED4 翻转），按右下角键应显示 15（LED0~3 全亮）。

如果键号和第 2 节的布局对不上，告诉我实际对应关系，我改 `sender_top.v` 里的键号映射。

## 7. 演示流程示例

1. 接好线，两块板上电，拨上 SW0，LED3 常亮表示链路正常。
2. 按 0 约 11 次，电压升到 3.410V，超过 3.400V 后看板弹出电压越限警告；再按 1 降回去。
3. 按 7 开启故障注入，温度跳到 65.0℃，超过 t-Hi 60.0℃，看板弹温度警告；再按 7 恢复。
4. 上电后按 12 四次选到 t-Hi（OLED 第 1 行显示 `T-HI`，键盘图 13/14 变成 `+THI` / `-THI`），按 13 两次调到 70.0℃，按 15 下发；再按 7 开故障注入，65.0℃ 不再报警。
5. 拨上 SW3 自动走片，看板上片号和良率随时间变化；拨上 SW2 叠加噪声，数据会小幅抖动。

## 8. 摄像头（OV5640）

模块插在 P2（左侧 40 针）最上端：模块 3.3V 对 P2-1，GND 对 P2-2，模块其余针依次对 P2-3~P2-18。上电后控制板自动配置摄像头（约 0.2 秒），之后连续采集 160x120 彩色画面，经视频串口发给看板。

| 信号 | P2 针 | FPGA 引脚 |
|---|---|---|
| SCL / SDA | 4 / 6 | R5 / T6 |
| VSYNC / HREF | 3 / 5 | T4 / T5 |
| RST / PWDN | 7 / 18 | T7 / P6 |
| PCLK | 16 | M6 |
| D0~D7 | 8 9 10 11 12 13 14 15 | T8 T9 R9 T12 R12 T13 N5 P5 |
| 视频串口 TX | 37 | P12 -> 看板 J2 第 15 脚（M1），GND 共地 |

视频串口 3.125Mbps 8N1，每行 `0xFF` + 行号（0~119）+ 160 字节（每字节 1 个 RGB332 彩色像素），约 7~8 帧/秒。

自检：拨上 SW5，按任意键依次翻页：

| 页 | 读作 | 含义 | 正常值 |
|---|---|---|---|
| `CAPt` | CAPT | 采集逻辑认到的帧/秒 | 约 15~30；`----` 配置中，`Err` 读不到芯片 ID |
| `U5yn` | VSYN | VSYNC 上升沿/秒 | 和 CAPt 相近；0 = VSYNC 没信号 |
| `Lin` | LIN | 两次 VSYNC 之间的行数 | 120 |
| `HLEn` | HLEN | 每行 HREF 高电平的 PCLK 数 | 320（反相时会远大于 320） |
| `PCL` | PCLK | PCLK 频率，MHz | 几十 MHz；0.0 = PCLK 没信号 |
| `dAtA` | DATA | 1 秒内跳变过的数据位 D7~D0（十六进制） | `FF`；某位为 0 说明那根线没信号 |
| `CHiP` | CHIP | 最近一次读到的芯片 ID（十六进制） | `5640`；`FFFF` 摄像头没应答，`0000` SDA 被拉低，其他值是通信时有时无 |
| `SEnd` | SEND | 每秒从视频串口发给看板的帧数 | 约 7~8；0 = 控制板没在发 |

看板第 4 页“产线监控”（PIC4）右侧是“现场画面 CAM-01”窗口：收到视频就显示彩色画面；没收到时显示背景图里的“等待现场画面”。其他页、菜单和缩略图界面不显示；出现警告横幅时，窗口让出横幅那两行。

显示 `Err` 时控制板每秒给摄像头断电复位一次重试，这期间其他诊断页读到的是悬空引脚的噪声，没有参考价值，先看 `CHiP` 页。

## 9. 现场视觉与云台（SW6）

拨上 SW6（SW5、SW7 不拨）进入现场视觉模式。控制板对摄像头画面做处理后再发给看板，看板“产线监控”页显示处理后的画面。这时按键不改工艺数据。

```
┌────┬────┬────┬────┐
│ 0  │ 1  │ 2  │ 3  │   原图   边缘   卷积    帧差分区
├────┼────┼────┼────┤
│ 4  │ 5  │ 6  │ 7  │   云台模式 灵敏度- 灵敏度+ 自动使能/关闭
├────┼────┼────┼────┤
│ 8  │ 9  │ 10 │ 11 │   人工确认 俯仰+  俯仰-   任务状态
├────┼────┼────┼────┤
│ 12 │ 13 │ 14 │ 15 │   水平-  回中   水平+   保存预置位
└────┴────┴────┴────┘
```

OLED 键盘图上对应标签：`SRC EDGE CONV MOVE / MODE SEN- SEN+ AUTO / ACK TLT+ TLT- TASK / PAN- HOME PAN+ SAVE`。

| 算法 | 数码管名称 | 画面 | 数码管数值 | 场景 |
|---|---|---|---|---|
| 原图 | `Src` | 彩色原图 | 每秒发送帧数 | 现场监看 |
| 边缘 | `EdGE` | 黑底白线（Sobel） | 边缘点占比 % | 外形轮廓、划痕 |
| 卷积引擎 | 见下表 | 3x3 卷积，键 2 切换卷积核 | 见下表 | 画质增强、特征提取 |
| 帧差分区 | `nove` | 和上一帧比，变化处标色；画出 A/B/C 工位分界线，正在报警的工位标红，其余工位标黄，其余压暗变灰 | 运动点占比 % | 人员闯入、机械臂动作 |

卷积引擎：按键 2 进入（第一个核是锐化），已在卷积模式时再按键 2 换下一个核，循环 5 种：

| 卷积核 | 数码管 | OLED | 运算 | 画面 | 数码管数值 |
|---|---|---|---|---|---|
| 锐化 | `SHrP` | `SHARP` | 拉普拉斯 [0 -1 0; -1 4 -1; 0 -1 0] 的灰度增量加回彩色 | 彩色、细节更清楚 | 发送帧率 |
| 降噪 | `bLur` | `BLUR` | 高斯 [1 2 1; 2 4 2; 1 2 1]/16，增量加回彩色 | 彩色、噪点减少 | 发送帧率 |
| 轮廓 | `LAP` | `LAPL` | 拉普拉斯取绝对值 | 黑底白轮廓 | 轮廓点（≥32）占比 % |
| 浮雕 | `Enbo` | `EMBOS` | 方向卷积 + 偏置 128 | 灰色浮雕 | 发送帧率 |
| 小 CNN | `Cnn` | `CNN` | 两层：Sobel 卷积 → 偏置 32 + ReLU → 3x3 最大池化（步长 1） | 加粗、去掉弱纹理的特征图 | 特征点（≥32）占比 % |

CNN 的第 1 层特征图存两行（每点 8 位），第 2 层在特征图上做 3x3 最大池化。所有卷积都只用加减和移位，不占乘法器。

- 灵敏度（`SEnS`）：某工位区运动点占比达到多少 % 算闯入，默认 5%，范围 1~50%，每按一次变化 1%。值越小越灵敏。
- 云台：水平 `PAn`、俯仰 `tiLt`，每按一次转 5°，范围 0~180°，上电和按 13 都回到 90°。
- 本版摄像头固定在控制板上；云台带动轻质指示箭头或巡检头模型，演示异常工位指向。云台转动时和停下后 1.5 秒内不做闯入判断，避免把箭头自身的运动当成闯入。

### 9.1 固定摄像头＋异常工位指向

摄像头同时拍到按从左到右排列的 A、B、C 工位，设备号 1/2/3 分别对应 A/B/C。当前一次处理所选设备的参数，不是三个工位同时采样。

自动控制上电默认关闭，预置位保存在易失寄存器中，每次重新上电都要重新保存。按以下顺序标定：

1. SW0 打开，SW2/SW3/SW5/SW7 关闭，参数保持正常。在 SW6 关闭时，用键 6 选设备 1（A）。
2. 打开 SW6，保持自动控制关闭。用键 12/14、9/10 把箭头调到 A，按键 15 保存当前设备的水平、俯仰角。
3. 关闭 SW6，用键 6 选设备 2（B），重复调节、保存；设备 3（C）同理。保存时应处于关闭、待机、人工接管或失败状态。
4. 自动范围默认水平 30~150°、俯仰 45~135°，超出范围不会保存。键 15 显示标定位掩码：A=1、B=2、C=4，例如 A/B/C 都保存后为 7；保存失败时掩码不增加。
5. 在 SW6 打开时按键 13 回中，按键 7 启用自动模式，随后可关闭 SW6，回到参数按键。关闭 SW6 不会关闭自动控制；SW5/SW7 会暂停自动控制。

以 B 工位温度异常为例：

1. SW6 关闭，选设备 2，按键 7 注入温度故障：默认从 35.0℃ 变成 65.0℃。SW0 保持打开以持续发送参数。
2. 看板在 LIVE 模式判断持续异常约 2 秒后回传状态；箭头按 B 的预置位移动，每 20ms 改变 1°，再等待 400ms，进入待人工复核。
3. 看板第 4 页现场画面仍显示完整的三个工位，中间区域出现橙框和 `CHECK B`。框表示待复核区域；警告横幅会遮住其经过的两行。框按设备号选取固定区域，没有图像目标识别。
4. 打开 SW6，按键 8 表示人员已查看。源温度仍异常时，看板告警与框线继续保留。确认状态显示在控制板，未增加回传看板的确认状态协议。
5. 关闭 SW6，再按键 7 取消注入。看板连续正常约 2 秒后撤销告警和框线，箭头回到水平、俯仰 90°，等待 400ms 后回到待机。

显示与接管：SW6 打开时按键 11 查看任务数值 `状态×1000＋错误×100＋设备号`，如 `5002` 表示 B 待复核（前导零可能消隐）。状态 0=关闭、1=待机、2=指向、3=等待、4=巡检、5=待复核、6=已人工确认、7=回中、8=失败、9=人工接管；错误 1=回传状态超时、5=当前角度越自动范围、6=任务超时、7=该设备未标定。通信中断约 2 秒或移动任务超过 15 秒时停止改变角度指令，保持当前位置指令；同一异常心跳不会自动重启失败任务。排除原因后，可关闭再启用自动控制重试。

方向键和回中键优先于自动任务，操作后进入人工接管，活动异常不会立即抢回控制；正常状态报文到来后释放接管。没有看板告警时，人工接管或失败状态 10 秒不按方向键也会自动释放回待机（巡检开着就继续巡检），所以标定时建议先把云台模式设为 `OFF`。自动关闭时同样可以手动调角，手动范围仍为 0~180°。人工接管或失败后的参数恢复仅释放到待机，不强制继续运动；如需回中，用键 13。自动关闭也保持当前角度指令，PWM 继续输出。

本版没有红标到位检测或视觉微调。状态 5 只说明角度指令和等待流程已完成，不证明舵机实际到位。视频中断会隐藏现场画面和框，但不取消独立的预置位动作。请称为“固定画面监控与异常工位指向演示”，舵机带动的是箭头，摄像头观察方向保持固定。

### 9.2 自动巡检与画面闯入联动

键 4 循环切换云台自动模式（OLED 第 2 行开头显示，数码管切到任务页）：

| 模式 | OLED | 巡检 | 闯入联动 |
|---|---|---|---|
| 关 | `OFF` | — | — |
| 巡检 | `PTRL` | 开 | — |
| 闯入 | `GUAR` | — | 开 |
| 两者 | `BOTH` | 开 | 开 |

自动模式要在自动控制开启（键 7，`AUTO` 反色）时才起作用，并且只用已标定的 A/B/C 工位。

- 巡检：没有任务时，箭头依次指向已标定的 A → B → C，每个停 3 秒，状态 4，任务数值的末位是当前指向的工位。只标定了一个工位时就一直指着它。
- 闯入联动：摄像头画面按列分成 A（0~52）、B（53~105）、C（106~159）三个工位区，与看板现场画面的 CHECK 框位置一致。每采一帧统计各区的运动点占比，OLED 第 2 行显示 `A xx B xx C xx`。某区占比达到灵敏度连续 2 帧，判为闯入，OLED 上该工位字母反色，箭头转向该工位并进入待复核（状态 5）。按键 8 确认后，等该区连续 8 帧低于灵敏度才回中，再继续巡检。闯入判断不依赖板间通信，看板不接也能用。
- 优先级：方向键 > 看板告警（`!G`）> 本地闯入 > 巡检。看板告警会打断巡检和闯入任务；看板告警处理期间不响应本地闯入。
- 云台转动时、以及停下后 1.5 秒内冻结闯入判断；摄像头 1 秒没有新帧时清除闯入状态。
- 帧差分区算法（键 3）能直接看到闯入判断的依据：运动点在报警工位标红、其余工位标黄。不在这个算法时，闯入统计照常进行。

舵机接线（每个舵机三根线）：

| 舵机线 | 接到 |
|---|---|
| 棕 / 黑（GND） | P2-40 GND，和独立电源的地共地 |
| 红（+5V） | P2-39 VBUS，或独立 5V 电源（推荐） |
| 橙 / 黄 / 白（信号） | 水平：P2-35（M12）；俯仰：P2-36（N12） |

PWM 为 50Hz，脉宽 0.5~2.5ms 对应 0~180°。两个舵机同时动或卡住时电流可超过 1A，只用 USB 供电容易让开发板复位，建议用独立 5V 电源。
